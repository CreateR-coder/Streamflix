# Streamflix

Streamflix is a Python-based application that allows users to search, discover, and browse information about movies and TV series using the TMDB (The Movie Database) API.

This repository is actively maintained with frequent daily feature updates and optimizations.

---

## Features

* **TMDB Integration:** Instantly search and view comprehensive details about movies and TV series.


* **Addon Ecosystem:** Expand application functionality using the companion [Streamflix Addon](https://www.google.com/search?q=https://github.com/CreateR-coder/Streamflix-Addon/).


* **Active Development:** Frequently updated (1–2 daily updates) to ensure bug fixes and new features.

---

## Prerequisites

* **Python:** Version 3.14.0 or higher (available at [python.org](https://www.python.org/)).



---

## Quick Start

1. Clone or download this repository.
2. Ensure Python 3.14.0+ is installed on your machine.


3. Run `python main.py` in your terminal or command prompt.

### Using with the Addon

To unlock full capabilities, run Streamflix together with the official addon:

1. Download and run the companion [Streamflix Addon](https://www.google.com/search?q=https://github.com/CreateR-coder/Streamflix-Addon/).


2. Run Streamflix simultaneously.


3. Navigate to `http://127.0.0.1:5000` in your web browser.
